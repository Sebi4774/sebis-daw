# Sebi's DAW (iPhone)

The phone version of Sebi's DAW. Open https://sebi4774.github.io/sebis-daw/ in Safari on the iPhone, tap Share, then Add to Home Screen.

It runs the same sound engines as the Windows app (compiled to WebAssembly) and opens and saves the same `.phsong` song files. Move songs between phone and PC with Save to Files / Open from Files in iCloud Drive.

The source lives in the project folder `phantom/mobile`; this repo holds the built app.
